This package is a ROS controller for a Mecanum wheel chassis, designed for the RoboMaster hero robot.

## Features
- Mecanum wheel inverse kinematics
- Mecanum wheel forward kinematics
- PID velocity control for each wheel using control_toolbox

## Dependencies
- ROS Noetic
- ros_control
- control_toolbox
